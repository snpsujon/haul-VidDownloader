API

Everything on this page uses a public REST API you can call from apps, scripts and browser extensions. Full reference at /api/docs.

# 1. Formats for a link
curl -X POST /api/info -H 'Content-Type: application/json' \
  -d '{"url":"https://youtu.be/…"}'

# 2. Start a download (video 1080p MP4, or "kind":"audio","audio_format":"mp3")
curl -X POST /api/jobs -H 'Content-Type: application/json' \
  -d '{"url":"https://youtu.be/…","kind":"video","height":1080}'

# 3. Progress, then the file
curl /api/jobs/JOB_ID
curl -OJ /api/jobs/JOB_ID/file
Download only content you own, content in the public domain, or content you have permission to save. You're responsible for respecting copyright and each site's terms. Files are deleted from the server after an hour.
