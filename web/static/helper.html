Haul PC helper

The helper lets the Haul extension save videos and audio straight to your computer, in full quality, with clips, playlists, subtitles and cover art. It works on Windows, Mac and Linux.

How to set it up
  1. Install the Haul extension in Chrome, Edge or Brave first.
  2. Download haul-helper.exe above and run it.
  3. If Windows shows "Windows protected your PC", click More info, then Run anyway.
  4. Restart your browser, then open the Haul extension. It should say the helper is ready.
