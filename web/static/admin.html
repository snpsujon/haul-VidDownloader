          YouTube cookies
          How to get cookies.txt
          1. Use a spare Google account, not your main one. YouTube can sign it out or flag it.
          2. In Chrome or Firefox, open a private window and sign in to YouTube with it.
          3. Install a "Get cookies.txt LOCALLY" extension and export cookies for youtube.com (Netscape format).
          4. Close the private window without signing out, so the cookies keep working.
          5. Upload the file here, or paste what's in it. The server checks it straight away.

          Server

          Versions, limits, and updating yt-dlp.

          Server

          Sites change and old yt-dlp versions stop working. Update yt-dlp now installs the newest one and restarts the server to load it as soon as nothing is downloading. Restarting needs Docker (or another process manager) to start the server again.

          Backup

          A zip of the settings, request log, phone pairings, YouTube cookies and the list of published files. Keep it private: the cookies sign in to YouTube. To restore, stop the server, put the files back in its data folder and start it again.
